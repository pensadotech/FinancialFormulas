

Kafka consumer key ideas
==============================

Kakfka message
--------------
A Kakfka message fundamental structure include a Key and a Value.
For the Key us primitive elements.
For thr Value can be from primitive to complex objects

var message = new message<string,Biometrics>  
	{
		Key = biometrics.DeviceId,
		Value = biometrics
	}

Important pieces
-------------------

The following steps represent a summary of pieces.

STEP 1: CREATE A BACKGROUND SERVICE
STEP 2: CONFIGURATION
STEP 3: CREATE A PRODUCER
STEP 4: CONSUME MESSAGES AND USE THEM


Important pieces general ideas
-------------------------------
 Important: This section is just a guide and provide a general idea of 
 the pieces at play. Consider looking into the code to understand all 
 small details needed.

 STEP 1: CREATE A BACKGROUND SERVICE

    * Create a background service that will run the consumer loop
    * Inside the ExecuteAsync method, create a consumer and subscribe to the topic
    * Inside the loop, consume messages and process them
    * Handle exceptions and commit offsets as needed

    For example 

     public class FormulaRequestConsumer : BackgroundService
     {
        public FormulaRequestConsumer()
        {
          // prepare elements needed here
        }

        protected override async Task ExecuteAsync(CancellationToken stoppingToken) 
        {
            while (!stoppingToken.IsCancellationRequested)
            {
                // read messages here   
            }
     }

STEP 3: CREATE A CONSUMER

        * Define a serializer for the message value (e.g. AvroSerializer<T>) 
          inside the constructor

            _avroDeserializer = new AvroDeserializer<GenericRecord>(schemaregistryClient);

        * Create a consumer inside the constructor

            _consumer = new ConsumerBuilder<string, byte[]>(consumerConfig).Build();

        * Complete idea is as follows

            private readonly KafkaMessagingOptions _options;

		       public FormulaRequestConsumer(
                    IOptions<KafkaMessagingOptions> options,   //  IOptions
                    IServiceScopeFactory scopeFactory,
                    IFormulaResponseProducer responseProducer,
                    ISchemaRegistryClient schemaregistryClient,
                    ILogger<FormulaRequestConsumer> logger)
               {
                 _options = options.Value;
                 _scopeFactory = scopeFactory;
                 _responseProducer = responseProducer;
                 _logger = logger;
                 
                 _avroDeserializer = new AvroDeserializer<GenericRecord>(schemaregistryClient);

                 var consumerConfig = new ConsumerConfig
                 {
                   BootstrapServers = _options.BootstrapServers,
                   GroupId = _options.ConsumerGroupId,
                   AutoOffsetReset = ParseAutoOffsetReset(_options.AutoOffsetReset),
                   EnableAutoCommit = false  // Disable auto-commit to manage offsets manually
                 };
                 
                 _consumer = new ConsumerBuilder<string, byte[]>(consumerConfig).Build();

               }
